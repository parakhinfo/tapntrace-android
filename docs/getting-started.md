# Getting Started with Tap & Trace

Tap & Trace is an on-device mobile web inspection suite for Android.

## 1. Download & Install (Version 1.0 - Free)
* Download the APK from **[https://tapntrace.renxlabs.in](https://tapntrace.renxlabs.in)** or GitHub Releases.
* Install the APK on your Android device (Android 8.0+).

## 2. Inspect Any Web Page
1. Open Tap & Trace and enter any URL (e.g. `https://news.ycombinator.com`).
2. Tap the **Inspect Icon (`AdsClick`)** in the top bar to activate Tap-to-Inspect.
3. Tap on any element on the page to view its DOM structure, CSS styles, and attributes.

## 3. Open DevTools Panels
* Tap the **Terminal Icon** to dock the DevTools panel (Console, Network Waterfall, Storage, Emulation).
* Split the view to see both the page and DevTools simultaneously.
